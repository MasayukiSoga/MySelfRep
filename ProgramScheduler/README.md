# ProgramScheduler

C# (.NET 8 / Windows Forms) の標準機能だけで作ったプログラム起動スケジューラです。外部ライブラリは使っていません。

## できること

- **指定時刻・曜日にプログラムを起動** (スケジュールごとに時刻と月〜日を設定)
- **実行方式を選択**
  - `順番に` … 上から順に、前のプログラムの終了を待って起動。「失敗時中断」をオンにすると、終了コードが 0 以外・タイムアウト時に以降を実行しません
  - `同時に` … 全プログラムを一斉に起動
- **グリッドで一覧表示・直接編集** (スケジュール一覧／プログラム一覧の 2 段構成)
  - 状態を色分け表示 (待機中=青, 実行中=黄, 成功=緑, 失敗=赤, スキップ/中止=灰)
  - 次回実行日時・前回実行日時・終了コード・所要時間を表示
- プログラムごとに 引数 / 作業フォルダ / タイムアウト(秒) を指定
- 「今すぐ実行」「中止」ボタンで手動実行・中止
- 実行ログを画面と `logs/yyyyMMdd.log` に出力
- 設定は exe と同じフォルダの `schedules.json` に保存
- 最小化するとタスクトレイに格納

## ビルド・実行

Windows + .NET 8 SDK で:

```
cd ProgramScheduler
dotnet run
```

配布用の単一 exe を作る場合:

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

Visual Studio 2022 では `ProgramScheduler.csproj` を開いて F5 で実行できます。

## 使い方

1. 上段「スケジュール一覧」の **追加** でスケジュールを作成し、名前・起動時刻(HH:mm)・実行方式・曜日を設定
2. 下段「プログラム一覧」の **追加** で実行ファイルを選択 (`.exe` `.bat` `.cmd` など)。順番は **▲ 上へ / ▼ 下へ** で変更
3. **保存** で設定を保存。アプリを起動している間、スケジューラが時刻を監視して実行します

※ アプリが起動している間だけ動作します。Windows 起動時から動かしたい場合は、スタートアップフォルダに exe のショートカットを置いてください。

## 構成

| ファイル | 内容 |
|---|---|
| `Models.cs` | `ScheduleGroup` (スケジュール) と `ProgramItem` (プログラム)。次回実行日時の計算もここ |
| `SchedulerEngine.cs` | 1 秒ごとに次回実行日時を確認し、`Process` で起動。順次/並列・タイムアウト・中止を処理 |
| `MainForm.cs` | 画面 (DataGridView 2 つ + ログ)、保存/読込 |
| `Program.cs` | エントリポイント |

スケジュール監視は UI スレッド上の `System.Windows.Forms.Timer` と `async/await` で動かしているため、グリッドにバインドされたモデルの更新はすべて UI スレッドで行われ、ロックや `Invoke` は不要です。
