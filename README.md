# MySelfRep

## tactics/ — クォータービュー SRPG バトル画面

スーパーファミコン版『タクティクスオウガ』の疑似立体バトル画面を、HTML5 Canvas で再現したデモです（画像素材は使わず、すべてコードでドット描画）。

`tactics/index.html` をブラウザで開くだけで動きます。

- マップ選択：「川辺の草原」(12×12)、「城門突破」(20×20)、「防衛線」(24×14)、「謁見の間」(16×16)、「敗走する将」(16×16)、「目覚めし巨像」(18×18)、「天空の渓谷」(16×16)、「灼熱の洞窟」(20×16)、「空中庭園」(18×18)、「雲海の空戦」(16×16)。マップは `tactics/maps.js` に追加できる
- 勝利条件：敵将撃破・全滅・N ラウンド耐久・拠点防衛。指定ラウンドに増援が出現
- 魔物（ゴブリン・ウルフ・オーク）と、4×4 マスの大型ユニット「ゴーレム」
- 飛行ユニット（妖精＝低空 / ペガサス・ペガサスナイト＝中空 / グリフォン・グリフォンライダー＝高空 / ガルーダ＝最高空）。高度で越えられる段差と地上からの攻撃の届き方が変わり、弓は対空に強い
- ユニットごとの思考ルーチン（突撃・慎重・守備・固守・狙撃・弱者狙い・激昂・拠点突破・護衛・移動・逃走）と、条件で起きるイベント（思考の切り替え・能力強化・台詞・増援・逃亡・勝敗決定）。デモ「敗走する将」
- オートバトル（A キー / ボタン）と早送り（F キー / ボタン）
- マップエディタ（`tactics/editor.html`）：高さ・地形・ユニット・増援・城門・防衛マス・勝利条件を編集し、実際のゲーム画面でプレビュー。テストプレイと maps.js 用コードの書き出しに対応
- 天井（低いと飛行ユニットが飛べず地上で置物に）、溶岩（上で止まると大ダメージ）、奈落・雲海（足場のない空）、吹き飛ばしによる転落（両手に盾のシールドナイトは 1〜2 マス吹き飛ばす）
- 最大 64×64 のマップとミニマップ（M キー）
- ZOC：相手に隣接するマスに入ると移動が止まる（高空の飛行ユニットは影響を受けない）。移動範囲では止まるマスを橙で表示
- 高さのあるひし形タイルのマップ（草原・荒れ地・岩場・砂地・川・石畳・城壁・木橋・瓦礫）
- ユニットやカーソルを隠す手前の城壁・崖は自動で半透明に
- 幅 4 マスのアーチ型の城門（HP 共有、損傷で割れが入り、破壊すると通行可能に）
- WT 制のターン順、移動範囲（高さ・ジャンプ力を考慮）、攻撃範囲の表示
- 高低差・背後／側面攻撃による命中率とダメージの変化、弓の高所射程ボーナス
- 移動・攻撃・魔法・待機（向き指定）、敵 AI、勝利条件（敵リーダー撃破）

操作: 矢印キーでカーソル、Z / Enter で決定、X / Esc でキャンセル、A でオートバトル、F で早送り。マウス・タップにも対応（タップは 1 回目で選択、2 回目で決定）。
