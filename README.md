# トリモード・アーケード

ひとつのフィールドを、ボタンひとつで RPG・ACT・STG の戦い方に切り替えて冒険するブラウザゲームです。場所も勇者の成長（レベル・HP・MP・ゴールド）もそのままで、変わるのは戦い方だけです。動かしているのはひとつの簡易物理エンジンです。

| スタイル | 戦い方 |
|---|---|
| RPG | モンスターのシンボルが透明になる。ぶつかると、そのモンスターとバトル画面でコマンドを選んで戦う |
| ACT | シンボルが見え、その場で剣とファイアで戦う |
| STG | シンボルが見え、魔法の弾を連射して戦う。敵も弾を撃ってくる |

どのスタイルもシンボルエンカウントです。フィールドのモンスターは切り替えても消えず、位置も残り HP もそのまま引き継がれます。

シンボル1つは最大30体の群れです（上限はレベルとともに増え、レベル5から30体）。RPG ではぶつかると群れ全員がバトル画面に並び、ACT・STG では先頭を倒すと次の1体が前に出てきます。バトルで攻撃してくるのは前列の3体までで、群れには敵全体に当たるフレア（MP 6）が効きます。

`index.html` をブラウザで開けば遊べます（サーバー不要）。画面上のボタンか `1` `2` `3` キーでスタイルを切り替えます。バトル中と会話中以外なら、いつでも切り替えられます。

## 操作

- 移動：矢印キー / WASD（画面の向きのまま動く）
- Z：話す・宝箱を開ける。ACT では剣、STG では魔法の弾（長押しで連射、向き固定）。バトルでは決定
- X / Space：ジャンプ（敵や弾を飛び越えられる）。バトルでは戻る
- C：ファイア（MP 3。STG では敵を貫通）
- H：当たり判定を表示
- R：やり直す（レベルや開けた宝箱はそのまま）

スマホでは画面下の十字キーと A・B・C ボタンで操作します。

## しくみ

| ファイル | 内容 |
|---|---|
| `src/engine/physics.js` | 簡易物理エンジン（当たり判定、壁との押し戻し、重なったときのイベント、高さ方向のジャンプ） |
| `src/engine/core.js` | 入力、シーン、ゲームループ、画面表示の共通部分 |
| `src/plugins/image-fit.js` | 物理エンジンのプラグイン。大きな画像を縮小して物体に合わせる。縮小方法は差し替えられる |
| `src/plugins/shrink-dot.js` | 縮小プラグイン「ドット化」。荒いドット絵に加工してから縮小する |
| `src/game/data.js` | モンスター・魔法のデータと、勇者の成長・ダメージ計算 |
| `src/game/sprites.js` | 勇者とモンスターの見た目 |
| `src/modes/field.js` | 共通のフィールド（斜め見下ろし） |
| `src/modes/styles.js` | RPG・ACT・STG の操作スタイル（攻撃ボタンの意味と、敵の見え方・ふるまい） |
| `src/modes/battle.js` | RPG スタイルのバトル画面 |

フィールドは内部では真上から見た2Dとして計算し、描画するときだけ斜めに変換しています。スタイルを切り替えても物理の設定は変わりません。

## プラグイン

物理エンジンには `world.use(plugin, options)` で機能を足せます。プラグインは次のうち必要なものだけを持つオブジェクトです。

| フック | 呼ばれるとき |
|---|---|
| `install(world, options)` | `use()` したとき1回 |
| `onAdd(body, world)` / `onRemove(body, world)` | 物体を追加・削除したとき |
| `beforeStep(world, dt)` / `afterStep(world, dt)` | 毎ステップの前後 |

### imageFit（画像の縮小）

大きな画像を、キャラクターの当たり判定の大きさに合わせて縮小します。ページ下の「画像で見た目を変える」から、手持ちの画像やサンプル画像で試せます。

imageFit が受け持つのは、どの縮小方法でも共通の部分です。

- 透明な余白を自動で切り取る
- 512px を超える画像は、最初に一度だけ 512px 以下にしておく
- 画面に実際に出る大きさ（拡大率込み）で縮小し、縮小方法と大きさごとに結果を覚えておく
- 当たり判定を画像の見えている部分に合わせる（`attach(..., { hitbox: true })`）

縮小のしかたそのものは「縮小プラグイン」として差し替えられます。ゲーム本体は「この大きさに縮めて」と頼むだけなので、あとから画質のよい縮小プラグインを足しても本体は変えなくて済みます。

| 縮小プラグイン | 中身 |
|---|---|
| `dot` ドット化（標準） | 仕上がりの2倍の細かさで荒いドットにし、透明度を2段階に、色を最大16色に減らしてから、2×2 ごとにいちばん多い色を選んで縮小する。外側のふちは少し暗くする |
| `smooth` なめらか | 面積平均。色に不透明度を掛けてから平均するので、半透明のふちが黒ずまない |
| `pixel` くっきり | 最近傍。色を混ぜない |

`shrink-dot.js` を読み込まなければ `smooth` が標準になります。

縮小プラグインを足すときは、RGBA の画素を縮めて返す関数を登録します。

```js
Game.plugins.imageFit.register('mine', {
  label: '自作の縮小',
  shrink(src, sw, sh, dw, dh, tools) {   // tools.resample などの道具が使える
    return new Uint8ClampedArray(dw * dh * 4); // dw × dh の RGBA
  },
}, { select: true });                      // すぐにこれを使う
Game.plugins.imageFit.select('smooth');    // あとから切り替え（読み込んだ画像すべてに反映）
```

```js
world.use(Game.plugins.imageFit);                       // world.skins ができる
const skin = Game.plugins.imageFit.fromImage(img);      // img / canvas から作る
world.skins.set('slime', skin);                         // 名前で登録して描画に使う
Game.plugins.imageFit.attach(body, skin, { maxW: 24, maxH: 24, hitbox: true });
                                                        // 当たり判定を画像の見えている部分に合わせる
```

