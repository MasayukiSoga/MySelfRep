# MySelfRep

## tactics/ — クォータービュー SRPG バトル画面

スーパーファミコン版『タクティクスオウガ』の疑似立体バトル画面を、HTML5 Canvas で再現したデモです（画像素材は使わず、すべてコードでドット描画）。

`tactics/index.html` をブラウザで開くだけで動きます。

- 高さのあるひし形タイルのマップ（草原・荒れ地・岩場・砂地・川）
- WT 制のターン順、移動範囲（高さ・ジャンプ力を考慮）、攻撃範囲の表示
- 高低差・背後／側面攻撃による命中率とダメージの変化、弓の高所射程ボーナス
- 移動・攻撃・魔法・待機（向き指定）、敵 AI、勝利条件（敵リーダー撃破）

操作: 矢印キーでカーソル、Z / Enter で決定、X / Esc でキャンセル。マウス・タップにも対応（タップは 1 回目で選択、2 回目で決定）。
