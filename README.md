# トリモード・アーケード

ひとりの勇者が、3つの戦い方で同じモンスターと戦うブラウザゲームです。レベル・HP・MP・ゴールドは全モード共通で、どのモードで倒しても経験値がたまります。動かしているのはひとつの簡易物理エンジンです。

| モード | 内容 |
|---|---|
| STG | 空のフィールドに現れたモンスターと魔法で戦う |
| ACT | 横スクロールのフィールドで、剣と魔法で戦う |
| RPG | 斜め見下ろしのフィールドを歩き、ランダムエンカウントしたらバトル画面でコマンドを選んで戦う |

`index.html` をブラウザで開けば遊べます（サーバー不要）。画面上のボタンか `1` `2` `3` キーでモードを切り替えます。

## 操作

- 移動：矢印キー / WASD
- Z：攻撃・魔法の弾・話す・決定
- X / Space：ジャンプ（バトルでは戻る）
- C：ファイア（MP 3）
- H：当たり判定を表示
- R：今のモードをやり直す

スマホでは画面下の十字キーと A・B・C ボタンで操作します。

## しくみ

物理エンジン（`src/engine/physics.js`）は3モードで共通です。モードごとに変えているのは設定だけです。

| 設定 | STG | ACT | RPG |
|---|---|---|---|
| 重力 | なし | 下向き | なし |
| 高さ z の重力 | なし | なし | あり（ジャンプ用） |
| タイルとの押し戻し | 使わない | 使う | 使う |
| 一方通行の床 | － | あり | － |

RPG は内部では真上から見た2Dとして計算し、描画するときだけ斜めに変換しています。

モンスター・魔法・勇者の成長（`src/game/data.js`）と見た目（`src/game/sprites.js`）も3モードで共通です。RPG のバトル画面（`src/modes/battle.js`）は物理エンジンを使わないコマンド式ですが、ダメージ計算と経験値は同じ関数を使っています。

## 開発

```sh
npm test        # 物理エンジンと各モードのテスト
npm run build   # dist/index.html に1ファイルにまとめて出力
```
