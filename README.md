# ゲーム情報管理アプリ

さくらのレンタルサーバ（共用プラン）にアップロードするだけで公開できる、
ブラウザからゲーム情報を**登録・修正・削除・問合**できる Python アプリです。
複数人で使えて、スマートフォンのブラウザからもそのまま操作できます。

## 特徴

- **追加インストールがほぼ不要** — Python 標準ライブラリ＋MySQL ドライバ 1 つだけ
- **フレームワーク不要** — Apache の CGI として動くので、設置は FTP アップロードのみ
- **`cgi` モジュール非依存** — Python 3.13 で削除されたモジュールを使っていないため、
  サーバ側の Python が更新されても壊れません（Python 3.8 以降で動作）
- **スマホ対応** — 1 カラムのカード表示、ダークモード対応、押しやすいボタン

## 利用者と権限

| | 一般利用者 | 管理者 |
| --- | --- | --- |
| 自分のゲーム情報 | 参照・登録・修正・削除 | 同じ |
| 他の人のゲーム情報 | **一切見えない** | 参照・修正・削除が可能 |
| 登録者で絞り込む | — | 可能 |
| 利用者管理 | — | 可能 |

- アカウントは**招待コードを知っている人だけ**が自分で作成できます
- **最初に登録した人が自動的に管理者**になります
- 管理者は、他の利用者のパスワード再設定・管理者権限の付与と解除・利用停止・削除ができます
- 管理者が 0 人になる操作（自分の権限を外す、最後の管理者を停止・削除する）は
  拒否されます。誰も管理できない状態に陥るのを防ぐためです

一般利用者の問合・修正・削除は、SQL の時点で常に自分の `user_id` で絞り込まれます。
URL の `id` を他人のデータに書き換えても取得できず「見つかりません」になります。

## 画面と機能

| 機能 | 内容 |
| --- | --- |
| 問合（一覧・検索） | キーワード（タイトル／よみ／メーカー／タグ／メモ）、機種、状態で絞り込み。並び替え・ページング付き。管理者は登録者でも絞り込めます |
| 登録 | タイトル必須。機種・ジャンル・メーカー・発売日・状態・評価・プレイ時間・所有形態・タグ・メモ |
| 修正 | 一覧／詳細から編集。入力エラーは項目ごとに表示 |
| 削除 | 確認画面を経由。POST + CSRF トークンがないと実行されません |
| CSV 書き出し | 絞り込み結果をそのまま Excel で開ける UTF-8（BOM 付き）で出力 |
| 新規登録 | 招待コード＋ログイン名＋表示名＋パスワード |
| アカウント設定 | 表示名の変更、パスワードの変更 |
| 利用者管理 | 管理者のみ。一覧、権限の付与と解除、利用停止、パスワード再設定、削除 |

## アップロードする前に（PC での確認）

PC に Python 3.8 以降があれば、**MySQL なしで**動作確認できます。
追加インストールは不要です。

```sh
cd tests
python3 run_tests.py      # 230 項目ほどを 1 秒以内に確認
python3 serve_local.py    # ブラウザで実際に触る
```

`run_tests.py` は、ファイルの揃い・文法・`index.cgi` の設定・`.htaccess` の
ソース隠蔽・秘密情報の同梱といった**設置前チェック**も行います。
詳しくは [tests/README.md](tests/README.md) を参照してください。

## 設置手順

### 1. データベースを用意する

さくらのサーバコントロールパネル →「Webサイト/データ」→「データベース」で
MySQL データベースを 1 つ作成します。表示される次の値を控えてください。

- データベースサーバ（例: `mysql3001.db.sakura.ne.jp`）
- データベース名（例: `yourname_game`）
- ユーザ名 / パスワード

> 文字コードは **UTF-8（utf8mb4）** を選んでください。

### 2. ファイルをアップロードする

`public/` の**中身**を FTP で公開ディレクトリ配下に置きます（例: `~/www/game/`）。

```
~/www/game/
├── index.cgi          ← パーミッション 755
├── .htaccess
├── app/               ← アプリ本体（Web からは見えません）
├── static/style.css
├── tools/make_secrets.py
├── schema.sql
├── config.ini         ← 次の手順で作成（パーミッション 600）
└── requirements.txt
```

`index.cgi` のパーミッションを **755** にしてください。

### 3. `index.cgi` の 1 行目をサーバに合わせる

SSH でログインして Python の場所を確認します。

```sh
which python3
```

表示されたパスを `index.cgi` の 1 行目（shebang）に書きます。

```python
#!/usr/local/bin/python3
```

### 4. MySQL ドライバを入れる

```sh
cd ~/www/game
python3 -m pip install -t vendor PyMySQL
```

`vendor/` に入れるのでサーバ全体を汚しません。PyMySQL は純 Python 実装なので
コンパイルが走らず、共用サーバでも問題なく入ります。

### 5. 設定ファイルを作る

```sh
cd ~/www/game
cp config.ini.sample config.ini
python3 tools/make_secrets.py      # secret_key と invite_code を生成
```

出力された 2 行を `config.ini` の `[app]` に貼り付け、
`[database]` に手順 1 の接続情報を記入します。

```sh
chmod 600 config.ini
```

### 6. 最初のアカウントを作る

`https://あなたのドメイン/game/` にアクセスすると新規登録画面が出ます。
招待コードを入力してアカウントを作ると、**その人が管理者**になります。
`users` / `games` テーブルは初回アクセス時に自動作成されます
（手動で作る場合は `schema.sql` を phpMyAdmin から実行してください）。

### 7. 他の人を招待する

招待コードを伝えれば、各自が `https://あなたのドメイン/game/?a=signup` から
アカウントを作成できます。全員の登録が済んだら `config.ini` の
`allow_signup` を `false` にして登録を閉じられます。

> パスワードを忘れた人がいる場合は、管理者が「利用者管理」→「パスワード再設定」
> で新しいパスワードを設定してください（メール送信機能はありません）。

## 設定項目（config.ini）

| 項目 | 説明 |
| --- | --- |
| `[app] title` | 画面に表示するアプリ名 |
| `[app] secret_key` | Cookie 署名用の秘密鍵。空なら `private/secret.key` を自動生成 |
| `[app] allow_signup` | 新規登録を受け付けるか。登録が済んだら `false` にできます |
| `[app] invite_code` | 招待コード。これを知る人だけがアカウントを作れます |
| `[app] per_page` | 一覧 1 ページあたりの件数（5〜100） |
| `[app] auto_migrate` | 起動時にテーブルを自動作成するか |

## セキュリティ上の作り

- **他人のデータの保護** — 一般利用者向けの問合・更新・削除はすべて SQL に
  `user_id` 条件が付きます。URL の `id` を書き換えても他人のデータには届きません
- **権限の分離** — 管理者限定の画面はルーティング表で指定し、
  画面を描く前に権限を確認します
- **SQL インジェクション対策** — 値は全てプレースホルダ経由。並び替えのカラム名は
  サーバ側の許可リストから選ぶ方式で、ユーザ入力を SQL に連結しません
- **XSS 対策** — HTML に出力する全ての値を `html.escape` でエスケープ
- **CSRF 対策** — 二重送信 Cookie 方式。更新・削除・権限変更は POST のみ受け付けます
- **パスワード** — PBKDF2-HMAC-SHA256（20 万回）で保存。比較は定数時間
- **総当たり対策** — 連続 5 回失敗したアカウントを 15 分間ロックします
- **セッション** — 利用者 ID と有効期限を HMAC 署名した Cookie。署名にパスワード
  ハッシュの指紋を含めるため、パスワードを変更すると他端末のログインは失効します
- **Cookie** — `HttpOnly` / `SameSite=Lax`、HTTPS 接続時は `Secure` を付与
- **ソース非公開** — `.htaccess` で `.py` `.ini` `.sql` `.md` を拒否。`app/` と `tools/` は
  ディレクトリ単位でも拒否（二重防御）
- **エラー内容の隠蔽** — 例外の詳細はサーバのエラーログにのみ出力し、画面には出しません

## 構成

```
public/
├── index.cgi            入口（これだけが Web から実行される）
├── app/
│   ├── main.py          全体の組み立て・利用者の特定・権限チェック
│   ├── web.py           CGI のリクエスト/レスポンス処理
│   ├── config.py        config.ini の読み込み
│   ├── db.py            MySQL 接続とテーブルの自動作成・移行
│   ├── auth.py          パスワードの照合、セッション、CSRF
│   ├── users.py         アカウントの作成・認証・管理
│   ├── games.py         登録・修正・削除・問合（SQL とバリデーション）
│   ├── errors.py        入力検証の共通例外
│   ├── templates.py     HTML 生成
│   └── views.py         画面ごとの処理とルーティング
├── static/style.css
├── tools/make_secrets.py
└── schema.sql
```

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 500 Internal Server Error | `index.cgi` の 1 行目のパスとパーミッション 755 を確認 |
| 「MySQL ドライバが未導入です」 | 手順 4 の `pip install -t vendor PyMySQL` を実行 |
| 「セットアップが未完了です」 | `config.ini` の設置と記入内容を確認 |
| パスワードを忘れた | 管理者が「利用者管理」→「パスワード再設定」で設定 |
| 管理者のパスワードを忘れた | phpMyAdmin で `users` の該当行を削除し、招待コードで再登録（最初の 1 人が管理者になります） |
| 文字化けする | データベースの文字コードが utf8mb4 か確認 |
| その他のエラー | サーバのエラーログに詳細が出力されます |
